Basic index route to test API

⚙️ PHASE 2 — Log Analysis Engine

Goal: Extract meaningful information from uploaded or pasted logs.

In app.py:

Read log file line-by-line.

Use regex to detect:

Error, Warning, Info counts

IP addresses

HTTP status codes

Timestamps or failed login attempts

Summarize analysis into dictionary:

result = {
    "total_lines": 250,
    "errors": 10,
    "warnings": 18,
    "unique_ips": ["192.168.0.1", "10.0.0.5"],
    "top_status_codes": { "404": 4, "500": 1 }
}


Save results as JSON in /reports

Redirect user to result.html with the summary.
