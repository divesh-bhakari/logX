# LogX — Intelligent Log Analysis Platform  
*A Modern, AI-Ready Log Forensics & Security Analytics System*

---

## 🚀 Overview  
LogX is a full-stack log forensics platform designed to deliver fast, accurate, and actionable insights from large log files.  
Built with Flask and MySQL, it processes **10K+ log entries** with **92% severity-detection accuracy**, offering automated parsing, interactive visualizations, and export-ready reports.  
AI-driven insight generation is currently in progress.

---

## 🔥 Key Features  

### 🧠 Smart Log Parsing & Classification  
- Regex-powered parsing for system, server, and custom logs  
- Automated severity detection with **92% accuracy**  
- Efficient handling of **10,000+ log entries**

### 📊 Interactive Visual Analytics  
- Real-time charts for severity distribution, timestamps, categories, and log frequency  
- Summary cards and detailed tables  
- Clean, responsive UI

### ⚡ Productivity & Workflow  
- CSV export for offline analysis  
- Error-resistant handling of inconsistent log formats  
- Support for multiple log sources

### 🔐 Authentication  
- Login and registration system  
- Secure password hashing  
- Session-based workflow

### 🤖 AI Integration (Ongoing)  
- Contextual log summaries  
- Threat/anomaly detection  
- Intelligent alerting

---

## 🛠️ Tech Stack  
**Backend:** Python (Flask), MySQL, Regex  
**Frontend:** HTML, CSS, JavaScript  
**Visualization:** Power BI, custom charts  
**Security:** Werkzeug hashing  
**Exports:** CSV  
**AI:** Integration in progress
